# claude-web 页面规范

配套文件：

- [ui/mockup.html](ui/mockup.html)：高保真参考稿，直接用浏览器打开（右上角可切换明暗）。**视觉以它为准。**
- [ui/tokens.css](ui/tokens.css)：颜色、字号、圆角、尺寸 token，原样复制进项目。

本文规定行为、尺寸和文案；mockup 规定长相。两者有冲突时，本文的行为、文案优先，mockup 的视觉优先。

## 0. 给实现者的硬性规则

1. **不加东西**：不加本文没写的按钮、设置项、页面、动画、提示语。觉得缺什么，先列出来问，不要自行补。
2. **只用 token**：组件里不出现裸色值、裸字号、裸圆角、裸阴影。Tailwind 默认色板已清空（见第 2 节），写 `bg-blue-500` 会直接失效。
3. **不用带样式的组件库**：不用 MUI、Ant Design、Chakra、DaisyUI、shadcn/ui 的默认样式。弹窗、下拉菜单、气泡只用 Radix 的无样式原语（`@radix-ui/react-dialog`、`react-dropdown-menu`、`react-popover`），样式自己按本文写。
4. **图标只用 lucide-react**：默认 16px，手机顶栏 20px，`strokeWidth={1.75}`。图标名见第 6.3 节。
5. **不要这些**：渐变、毛玻璃、发光、彩色大背景、emoji、头像、插画、骨架屏闪光动画、卡片阴影（阴影只给浮层）。
6. **文案逐字使用第 8 节**，不改写、不加感叹号。
7. 完成后按第 9 节验收，并与 mockup 截图并排对比。

## 1. 设计原则

- **像工具，不像聊天软件**：Claude 的回复不加气泡，像文档一样平铺；只有用户消息用浅灰块。
- **安静**：界面大面积是中性灰，强调色只出现在主按钮、运行中状态和选中态。颜色用来表达状态，不做装饰。
- **状态一眼可见**：会话运行中、待确认、空闲、未运行，用固定的颜色和形状区分，在列表、标题栏、手机顶栏里保持一致。
- **工具调用默认收起**：一行摘要说清楚做了什么；需要时再展开。
- **待确认的事放在手边**：审批卡、提问卡出现在输入框的位置，不会被消息流冲走。

## 3. 布局与断点

| 宽度 | 布局 |
|---|---|
| ≥1024 | 三栏：侧栏 + 对话 + 右侧面板。侧栏和面板都能收起、都能拖动调宽（见 3.1） |
| 640–1023 | 只有对话；侧栏、面板改为从两侧滑出的抽屉（宽 `min(默认宽度, 90vw)`，带 `shadow-overlay` 和遮罩，不能拖宽），点遮罩或按 `Esc` 关闭 |
| <640 | 手机两级页面：会话列表页 → 会话页；会话页顶部分段切换「对话 / 文件 / Diff」 |

- 对话内容列最大宽 760，居中，左右内边距 24（手机 16）。
- 手机底部留 `env(safe-area-inset-bottom)`；顶部留 `env(safe-area-inset-top)`。mockup 里的 44px / 34px 空白就是模拟安全区。
- 360px 宽时不能出现横向滚动。

路由：

| 路径 | 内容 |
|---|---|
| `/` | 桌面：打开最近一个会话，没有会话时显示空状态；手机：会话列表 |
| `/s/:sessionId` | 会话页 |
| `/s/:sessionId?tab=files&path=...` | 手机：文件分段；桌面：右侧面板打开「文件」 |
| `/s/:sessionId?tab=diff` | 手机：Diff 分段；桌面：右侧面板打开「Diff」 |

### 3.1 收起与调宽（≥1024）

见 mockup A（展开、手柄悬停态、折叠的项目组）和 A2（两侧都收起）。

**收起 / 展开**

| | 收起按钮 | 收起后的展开按钮 | 快捷键 |
|---|---|---|---|
| 左侧栏 | 侧栏头部最右 `PanelLeftClose` | 标题栏最左 `PanelLeftOpen` | `Ctrl/⌘+B` |
| 右侧面板 | 面板头部最右 `PanelRightClose` | 标题栏最右 `PanelRightOpen` | `Ctrl/⌘+Alt+B` |

- 展开按钮只在对应一侧收起时出现，展开后消失。
- 左侧栏收起时，如果有任何会话处于待确认，`PanelLeftOpen` 右上角显示 7px `warn` 圆点（外加 2px `bg` 色描边），点开侧栏后才能看到是哪个会话。
- 收起和展开没有动画，直接切换。
- 在 640–1023 抽屉模式下，同样的按钮和快捷键改为开关抽屉。

**拖动调宽**

- 侧栏右边缘、面板左边缘各有一个拖拽手柄：命中区宽 8px，骑在分隔线上；常态不可见（只看到 1px `line` 分隔线），悬停或拖动时显示 2px `accent` 竖线，光标 `col-resize`。
- 宽度范围：侧栏 220–420（默认 280），面板 360–800（默认 480）。实际宽度写到 `--sidebar-w` / `--panel-w` 变量上。
- 拖动时宽度跟手，不加过渡。手柄用 `setPointerCapture` 接管指针，拖动期间给 `body` 加 `user-select: none` 和 `cursor: col-resize`。
- 往窄处拖过下限 60px 以上（侧栏 <160、面板 <300）时直接收起，松手后保持收起；没松手前往回拖会重新展开。
- 双击手柄恢复默认宽度。
- 手柄可以用 Tab 聚焦（`role="separator"`，`aria-orientation="vertical"`，带 `aria-valuenow/min/max`），聚焦时显示 `accent` 竖线，`←` / `→` 每次调 16px，`Enter` 收起。

**对话区最小宽度 480**

- 拖宽时，最大宽度同时受「对话区不小于 480」限制。
- 展开面板或窗口变窄时，如果对话区会小于 480：先把面板缩到下限；还不够就自动收起左侧栏，并记住这次收起是自动的。等空间重新够了（面板收起或窗口变宽），自动收起的左侧栏自己恢复；用户手动收起的不恢复。

**记忆**

以下状态存 localStorage（读写包 try/catch，读不到就用默认值），刷新后保持：

| key | 内容 |
|---|---|
| `cw.sidebar` | `{ open, width }` |
| `cw.panel` | `{ open, width, tab }` |
| `cw.groups.collapsed` | 已折叠的项目组 `cwd` 列表 |

## 4. 页面

### 4.1 侧栏 / 手机会话列表（mockup A 左栏、B）

自上而下：

1. 头部（桌面高 48，手机高 52）：`claude-web`（桌面 14px / 手机 18px，600）；桌面右侧为主题按钮和 `PanelLeftClose`（收起侧栏）；手机右侧为 `Plus`（新建会话）和 `MoreHorizontal`（主题切换）。
2. 搜索框：按标题、首条消息、目录名过滤，实时生效。桌面 `Ctrl/⌘+K` 聚焦。
3. 桌面：「新建会话」按钮（次要按钮，占满宽度，左对齐）。
4. 列表：
   - 第一组固定为「待确认」，放所有 `waiting` 状态的会话（这些会话不再出现在所属项目组里）；没有时不显示这一组。这一组不能折叠。
   - 其余按项目（`cwd` 的最后一级目录名）分组，组按最近活动时间排序，组内按 `lastModified` 倒序。组名后跟数量；鼠标悬停显示完整路径。
   - 每组最多显示 5 个，多出时组末显示「显示全部 N 个」。
   - 项目组可折叠：组名前有 `ChevronDown`（展开）/ `ChevronRight`（折叠），点整个组名行切换。折叠后只剩组名行；组内如果有运行中或空闲（进程还活着）的会话，组名后显示对应状态点，运行中优先。折叠状态按 `cwd` 记忆（见 3.1）。
   - 当前打开的会话所在的组被折叠时，不强制展开。
   - 搜索时忽略折叠状态，所有匹配结果都展开显示；清空搜索后恢复原来的折叠状态。
5. 桌面底部：上面是额度块（见 4.6），下面一行 `● N 个运行中 · 上限 M`；没有运行中的会话时显示「没有运行中的会话」。
6. 手机：列表底部固定一条额度条（见 4.6）。

会话项：

| 元素 | 规格 |
|---|---|
| 状态点 | 8px，见第 6.1 节 |
| 标题 | `customTitle` 优先，否则 `summary`；单行省略；桌面 13px，手机 16px |
| 时间 | 右上，12px `fg-3`，格式见第 8.3 节 |
| 第二行 | 「待确认」组里显示「项目 · 分支」；其他组桌面显示 `GitBranch` 图标 + 分支名，手机只显示分支名 |
| 选中态 | 白底（`surface`）+ 1px `line` 边框 |
| 尺寸 | 桌面内边距 8/10、圆角 6；手机内边距 12/16、行间用 1px `line` 分隔，无圆角 |

### 4.2 会话页（mockup A 中栏、C、D）

**标题栏**（桌面高 48 / 手机高 52）：

- 桌面：[`PanelLeftOpen`，仅左侧栏收起时] + 标题（14px 600，单行省略）+ 下方一行元信息（`~/dev/claude-web · 分支`，路径用等宽字体）；右侧依次为状态徽标、`MoreHorizontal`、[`PanelRightOpen`，仅右侧面板收起时]。640–1023 时最左固定为 `Menu`（开侧栏抽屉），最右固定为 `PanelRightOpen`（开面板抽屉）。
- 手机：`ArrowLeft` 返回 + 标题（16px 600）+ 元信息行（`● 状态 · 路径`）+ `MoreHorizontal`。手机不显示状态徽标，状态并入元信息行。
- 「更多」菜单：「释放进程」（仅在有 Runtime 时显示）、「复制恢复命令」（复制 `claude --resume <id>`）、「在此目录新建会话」。
- 手机标题栏下方是分段控件「对话 / 文件 / Diff」，高 34，左右边距 16。

**连接横幅**：WS 断开超过 1 秒时，在标题栏下方出现高 28 的 `warn-soft` 条：spinner +「连接已断开，正在重连…」；重连后消失。

**消息流**：渲染规则见第 5 节。

**底部区域**（自上而下，与消息列同宽）：

1. 「↓ 新消息」浮动按钮：用户上滑离开底部且有新内容时出现，悬浮在底部区域上方居中；点击滚到底。
2. 任务条：会话出现过 TodoWrite 时显示。收起态一行：`ListChecks` +「任务 2/4」+「当前：<进行中的任务>」+ `ChevronUp`；点击展开成卡片列出全部任务（mockup H 右下）。全部完成后显示「任务 4/4 · 已全部完成」，下一轮用户发消息后隐藏。
3. 额度已达上限时的提示条（见 4.6）。
4. 下面三者只显示一个，优先级：审批卡 > 提问卡 > 输入框。

**输入框**（mockup A、A2 底部，F）：布局参照 Claude Code 官方 VS Code 客户端，上面是输入区，下面隔一条 1px `line` 分隔线是高 44 的工具栏。

输入区：

- 多行自动增高，桌面最多 8 行、手机最多 5 行，超出后内部滚动。内边距 12/14/10，正文 15px，手机 16px（防止 iOS 聚焦时缩放）。
- 占位符：桌面「输入消息，/ 调用命令，@ 引用文件」，手机「输入消息」。
- 有图片附件时，输入区顶部先显示一排缩略图（56×56，圆角 6，1px `line` 边框，间距 10；右上角 18px 圆形删除按钮，`fg` 底 `bg` 色 `X`）。点缩略图在新标签页打开原图。

工具栏从左到右：

| 项 | 样式 | 行为 |
|---|---|---|
| 「+」 | 图标按钮 `Plus` | 弹出菜单：「上传图片」（第二行说明「也可以直接粘贴或拖进输入框」）、「引用文件」（右侧提示 `@`） |
| 「/」 | 图标按钮 `SquareSlash` | 弹出命令菜单，等同于在空输入框里输入 `/`。手机不显示这个按钮 |
| 缓存倒计时 | `Clock` + 剩余时间，13px，无底色 | 见下方「缓存倒计时」 |
| 上下文用量 | 16px 圆环 + 百分比，13px | 只在用量 ≥50% 时出现；≥80% 变 `warn` 色。悬停提示「上下文已用 62%（124k / 200k）」。不可点击。手机不显示 |
| 额度 | `Gauge` +「额度 86%」，13px | 只在额度偏高或已达上限时出现，见 4.6。手机只显示 `Gauge` + 百分比 |
| 模型 | 胶囊：`surface-2` 底、高 28、圆角全圆；模型名 `fg` + 思考强度 `fg-3`，如「Opus 5.5 高」 | 弹出「模型与思考强度」菜单。模型不支持思考强度时只显示模型名。手机只显示模型名 |
| （弹性空白） | | |
| 权限模式 | 文字按钮：图标 + 模式名，13px `fg-2`，无边框 | 弹出权限模式菜单。手机只显示图标，按钮 40×40 |
| 发送 / 停止 | 32×32 圆角 8 | 见下方状态表 |

除模型胶囊外，工具栏各项都是高 32 的透明按钮，hover 时 `surface-3` 底；间距 2。

权限模式：

| 模式 | 名称 | 图标 | 说明（菜单第二行，`fg-2`） |
|---|---|---|---|
| `default` | 编辑前询问 | `ShieldCheck` | 改文件或执行命令前都会询问 |
| `acceptEdits` | 自动编辑 | `CodeXml` | 改文件不再询问，执行命令仍会询问 |
| `plan` | 计划模式 | `ClipboardList` | 只读分析，先给方案，不做改动 |

发送按钮：

| 状态 | 按钮 |
|---|---|
| 没有输入也没有附件、会话不在运行 | `ArrowUp`，`surface-3` 底 `fg-3` 图标，不可点 |
| 有输入或附件 | `ArrowUp`，`accent` 底 |
| 会话运行中且输入为空 | `Square`（实心），`fg` 底 `bg` 色图标，点击中断 |

缓存倒计时：

- 显示提示缓存（prompt cache）还有多久过期。数据来自后端的 `meta.cache`（见 design.md 5.3）：`refreshedAt` 是主会话最近一次 API 响应的时间，`ttlSec` 是缓存时长（300 或 3600）。剩余时间 = `refreshedAt + ttlSec − 现在`，前端每 15 秒刷新一次。
- 显示格式：向上取整的分钟数加 `m`，如「58m」；不足 1 分钟显示「<1m」；过期显示「已过期」。
- 颜色：剩余 >5 分钟为 `fg-2`；≤5 分钟为 `warn`；过期为 `fg-3`。
- 悬停提示（手机为点按）：未过期时「提示缓存还剩 N 分钟（1 小时缓存 / 5 分钟缓存）。过期后，下一条消息要重新写入缓存，消耗的用量更多。」；过期后「提示缓存已过期，下一条消息会重新写入缓存。」
- 没有 `meta.cache`（新会话还没发过消息、或拿不到缓存时长）时不显示这一项。

弹出菜单（mockup F）：

- 统一样式：`surface` 底、1px `line` 边框、圆角 10、`shadow-overlay`、内边距 4；菜单项内边距 7/10、圆角 6，当前项 `surface-2` 底，已选中项右侧 `Check`。
- 都从工具栏向上弹出，左缘对齐触发按钮（权限模式菜单右缘对齐）；上方空间不够时向下。`↑` `↓` 移动高亮，`Enter` 选中，`Esc` 关闭并把焦点还给输入框。
- **模型与思考强度**：上半部分「模型」列出 `supportedModels()` 的每一项（`displayName` + 第二行 `description`）；下半部分「思考强度」是分段控件，只列当前模型 `supportedEffortLevels` 里有的档位，按 低 / 中 / 高 / 超高 / 最高（`low` / `medium` / `high` / `xhigh` / `max`）的顺序排列。切换只影响当前会话，不写入设置文件。模型切换在当前回合内生效；思考强度从下一回合生效，切换后在菜单底部显示一行 `fg-3`「下一回合生效」，直到下一回合开始。

### 4.6 账号额度（mockup A 左下、B 底部、G）

显示订阅账号的用量额度，内容和终端里的 `/usage` 一致。数据来自 WS 推送的 `usage`（见 design.md 5.5），前端只负责展示。

**额度行**：服务端返回的 `limits` 每一项是一行。按返回的顺序展示，按 `group` 分组，不增删、不重排。

行名按 `kind` 判断（不要按其他字段猜）：

| `kind` | 行名 |
|---|---|
| `session` | 当前时段 |
| `weekly_all` | 所有模型 |
| `weekly_scoped` | `scope.model.display_name`，没有就用 `scope.surface.display_name` |
| 其他 | `scope` 里的 `display_name`，都没有就显示 `kind` 原文 |

组名：`session` →「时段」，`weekly` →「每周」，其他显示 `group` 原文。

颜色按 `severity`：`normal` 时百分比 `fg`、进度条 `fg-2`；`warning` 时都用 `warn`；`critical` 时都用 `danger`；不认识的值按 `normal`。

进度条：高 4，全圆角，轨道 `line`，填充宽度 = `percent`%（超过 100 按 100）。

重置时间（`resets_at`，按本地时区）：

| 距重置 | 格式 |
|---|---|
| 不到 1 小时 | 41 分钟后重置 |
| 不到 24 小时 | 2 小时 41 分后重置（整点时为「2 小时后重置」） |
| 7 天以内 | 周四 09:00 重置 |
| 更久 | 11月3日 09:00 重置 |
| `null` | 不显示 |

**桌面侧栏底部额度块**：

- 可点击，圆角 6，内边距 8/10，hover 时 `surface-3` 底。
- 第一行 12px：`Gauge`（14px）+ 行名（`fg-2`）+ 弹性空白 + 百分比（600，按 `severity` 着色）。第二行是进度条。
- 显示哪一行：`is_active` 为 `true` 的那行；没有就取第一行。
- 点击后向上弹出额度浮层，左缘对齐额度块。

| 状态 | 额度块 |
|---|---|
| 首次读取，还没有数据 | 旋转的 `LoaderCircle` +「额度读取中…」，`fg-3`，没有进度条 |
| 读不到（`usage.error === "unavailable"`） | `Gauge` +「额度不可用」，`fg-3`，没有进度条；仍可点开看原因 |
| 已达上限（见下方「已达上限」） | 行名换成「已达上限」，右侧「14:30 恢复」，整行 `danger`，进度条满格 `danger` |

**额度浮层**（宽 300，样式同 4.2 的弹出菜单）：

1. 头部：Claude 账号邮箱（13px，单行省略）+ 右侧套餐标签（`subscriptionType` 首字母大写，如「Max」；12px，`surface-2` 底、1px `line` 边框、圆角 4）。没有账号信息时不显示头部。
2. 按组列出额度行：组名用菜单分组标题样式；每行内边距 6/10，第一行行名（13px `fg`）+ 右侧百分比（13px 600），第二行进度条，第三行重置时间（12px `fg-3`）。
3. 有 `extra_usage` 时，分隔线后加一行「额外用量」：
   - 金额用 `Intl.NumberFormat` 按 `currency` 格式化。服务端给的是最小货币单位，先除以 10 的「该币种小数位数」次方（USD 为 100）。
   - 有 `monthly_limit` 时显示「$12.40 / $50.00」，进度条按 `used_credits / monthly_limit` 画。
   - `monthly_limit` 为 `null` 时只显示「已用 $12.40」，不画进度条，也不要写「无上限」（Team / Enterprise 的上限可能在组织那边）。
   - `is_enabled` 为 `false` 时显示「额外用量未启用」，`fg-3`。
4. 底部：分隔线 +「更新于 N 分钟前」（12px `fg-3`，1 分钟内为「刚刚更新」）+ 右侧 `RefreshCw` 图标按钮。刷新中图标旋转、按钮禁用。最近一次刷新失败时，这行文字变成 `warn` 色的「更新失败，显示的是 N 分钟前的数据」。
5. 读不到额度时，整个浮层只有一段 13px `fg-2` 的说明：「当前登录方式读不到额度。用订阅账号登录 Claude Code 后才能显示。」
6. 打开浮层时，如果数据已超过 1 分钟，自动发一次 `usage.refresh`。

**输入框工具栏「额度」项**：

- 出现条件：`is_active` 那行的 `severity` 为 `warning` / `critical`，或已达上限。`normal` 时不显示。
- 内容：`Gauge` +「额度 86%」；`warning` 为 `warn` 色，`critical` 和已达上限为 `danger` 色。位置在上下文用量之后、模型胶囊之前。
- 悬停提示：「当前时段额度已用 86%，2 小时 41 分后重置。」（行名和重置时间按上面的规则）。
- 点击打开额度浮层，从工具栏向上弹出。

**已达上限**：`usage.limited` 不为空且还没到 `resetsAt` 时，所有会话的输入框上方都出现一条提示：

- 样式：`danger-soft` 底、1px `danger` 30% 透明度边框、圆角 10、内边距 8/12、13px `danger` 字，左侧 `TriangleAlert`。

**手机**：

- 会话列表底部固定一条额度条：上边框 1px `line`，内边距 12/16（底部再加安全区），13px `fg-2`；从左到右 `Gauge`、行名、进度条（占满剩余宽度）、百分比、`ChevronRight`。点按打开底部弹层「账号额度」。

## 5. 消息流渲染

### 5.1 间距与基本块

- 块与块之间 16px；连续的工具行之间 6px（组成一组）。
- **用户消息**：右对齐，最大宽 85%，`surface-2` 底 + 1px `line` 边框 + 圆角 10，内边距 8/14，15px。
- **Claude 文本**：无背景、无边框，15px / 行高 26。Markdown：段落间距 10；列表缩进 20；行内代码等宽 0.87em、`surface-2` 底、1px `line` 边框、圆角 4；代码块 `surface-2` 底、1px `line` 边框、圆角 6，头部一行语言名 + `Copy` 图标按钮；链接用 `accent` 色。标题（h1–h3）一律按 15px 600 渲染，不放大。
- **流式输出**：逐字追加到当前文本块，不显示光标。用户发送后到第一个字出现之前，显示一行 `fg-3` 的 spinner +「思考中…」。
- **思考块**：一行 `ChevronRight` +「思考 · N 秒」（无时长时只写「思考」），13px `fg-3`；点开后显示思考内容，13px `fg-2`。
- **结束行**：每轮 `result` 后显示居中细线 +「完成 · 2 分 14 秒 · 8 轮」（12px `fg-3`）。中断显示「已中断」；出错显示「出错：<错误类型>」（`danger` 色）。不显示费用。

### 5.2 工具行

结构：高 34，内边距 0/10，1px `line` 边框，圆角 6，`surface` 底。从左到右：展开箭头（可展开时才有）、工具图标（`fg-3`）、工具名（13px 600）、摘要（等宽 12.5px `fg-2`，单行省略）、右侧信息（12px `fg-3`）、状态图标。

状态：

| 失败 | 右侧 `X`（`danger` 色）；边框为 `danger` 35% 混 `line`；**默认展开** |
| 已拒绝 | 摘要加删除线，右侧「已拒绝」+ `Ban`（`fg-3`） |

| 其他 | `Wrench` | 输入 JSON 压成一行 | — | 输入 JSON 与结果 | 收起 |

### 5.3 滚动

- 打开会话时滚到底部。
- 距底部 80px 以内视为「在底部」，新内容到来时自动跟随；否则不动，显示「↓ 新消息」按钮。
- 展开、收起工具行不触发自动滚动。

## 9. 验收

1. 在 1280×800、1024×768、390×844、360×740 四个尺寸，浅色、深色各截一张图，与 mockup 对应画面并排对比，颜色、字号、间距、圆角一致。
2. 代码里搜 `#[0-9a-fA-F]{3,8}`、`rgb(`、`px` 字号写死：除 tokens.css 和第 2 节的 app.css 外不应出现。
3. 360px 宽无横向滚动；手机上所有可点击元素不小于 40×40。
4. 键盘：Tab 顺序合理，focus-visible 外框可见；Enter / Shift+Enter / Esc / `Ctrl+K` / `Ctrl+B` / `Ctrl+Alt+B` 行为符合 3.1 和 4.2。
5. 收起与调宽：两侧分别拖到上下限、拖过下限 60px 收起、双击复原、刷新后宽度和开关状态保持；1024 宽打开面板时左侧栏自动收起，关掉面板后自动恢复；任何时候对话区不小于 480。
6. 打开系统「减少动态效果」后，没有任何动画。
7. 输入框：与 mockup A2、F 对比工具栏顺序和样式；缓存倒计时在发消息后重置、跨 5 分钟阈值变色、过期显示「已过期」；粘贴、拖入、选择三种方式都能加图片；`/` 和 `@` 菜单能用键盘完成选择。
8. 账号额度：与 mockup A、B、G 对比；服务端返回未知的 `kind` / `group` / `severity` 时仍能显示；`monthly_limit` 为 `null` 时没有写「无上限」；收到 `rate_limit_event`（rejected）后所有会话的输入框上方都出现提示，到重置时间后自动消失。
9. 逐条核对第 5.2 节的工具映射表和第 8 节文案。
